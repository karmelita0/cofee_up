# Веб-приложение «Заказы учебного кафе»
Учебная практика УП.09.01, вариант 19.

## Стек технологий и версии
- Язык: PHP 8.1 (PDO)
- База данных: MySQL 8.x
- Веб-сервер: OpenServer 
- Среда разработки: Windows, VS Code

## Запуск проекта
Для запуска встроенного локального сервера выполните в корне проекта:
```bash
php -S localhost:8000
